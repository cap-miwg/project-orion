How to use

For sponsors & leadership

Lead with the master brochure for context, then include the relevant kit brochures for the build being proposed. Most reviewers want the cover sheet and the Bill of Materials.
For another Wing

Replicating ORION

The brochure pack pairs with the Architecture page — that document covers the IP plan, dial plan, TAK federation, and governance questions a sister Wing needs to coordinate on.
Printing

Print at 8.5 × 11 in

Designed for letter, double-sided. Color is recommended (the navy + yellow palette doesn't carry well in grayscale). Borderless print preferred.
Need a different format?

Source HTML is in the repo. Edit, fork, or rebrand.

The brochure source HTMLs live in /brochures/. Each is a single self-contained file with all CSS inline — open in Chrome, print to PDF, and you have a new brochure. Useful for sister Wings adapting the program.
