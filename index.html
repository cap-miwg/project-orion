The Premise

Civil Air Patrol's voice and radio communications are mature. The data side has not kept pace.

Personal hotspots fail in rural areas. Wi-Fi coverage is fragmented. There is no shared file system, no consistent dashboards, and limited interoperability with partner agencies. ORION is an architecture of standardized kits, built on commercial UniFi networking and Starlink backhaul, that turns mission connectivity from an improvised setup into a Wing-wide capability.

Modular by default

Each kit functions standalone and meshes seamlessly with others when colocated.

One ecosystem

UniFi for the network plane, Starlink for the WAN backhaul. No recurring license fees on the management plane.

Federation, not centralization

Each Wing runs its own controller and TAK server. Common naming, IP plan, and dial plan make multi-Wing missions work.

Field-replaceable hardware

Commercial off-the-shelf. No proprietary bus. No vendor lock-in beyond a single network family.

Volunteer-supportable

If a member with reasonable IT comfort can't deploy or troubleshoot the kit, the design has failed.

Availability first

CAP missions live or die on whether the network works when staff arrive on-scene, often in degraded conditions.

The Five Kits

Modular by design. Federated by default.

Each kit is a complete, standalone capability. When two or more kits are colocated, they mesh into a single coherent network. Build the lineup incrementally — one node at a time, one Wing at a time.

001 ORION-Core Wing HQ controller and primary anchor for the architecture.
002 ORION-Trailer Rapid-deploy mobile core in the comms trailer.
003 ORION-Base Mission base extension for staff in a building or hangar.
004 ORION-Fleet Every Wing vehicle becomes a network node with TAK tracking.
005 ORION-Air In-flight connectivity for live aerial imagery and TAK position. Concept

Path Forward

Funded grassroots. Built to last.

Phase 1 stands up the architecture in Michigan Wing as the proof of concept. From there, results build the case for National engagement and a sustainable CAP-USAF line item. Standardized kits make every subsequent Wing's adoption faster, cheaper, and lower risk.
